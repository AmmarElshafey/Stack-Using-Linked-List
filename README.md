# Stack-Using-Linked-List
This project demonstrates a simple and efficient implementation of a **Stack** data structure using a singly linked list in C++.
It covers essential stack operations like push, pop, peek (top), count, clear, print, and search.

## 📚 Overview

Stacks follow the **LIFO** (Last-In-First-Out) principle. This implementation dynamically allocates memory for each element using linked nodes,
making it more memory-efficient than array-based stacks when the size of the data is unknown.

## 🚀 Features

- ✅ Push an element onto the stack
- ✅ Pop (remove) the top element
- ✅ Peek at the top element
- ✅ Check if the stack is empty
- ✅ Count the total elements in the stack
- ✅ Print the entire stack
- ✅ Search for a specific value in the stack
- ✅ Clear all elements from the stack safely
- ✅ Automatic memory cleanup (via destructor)

## 🛠 How to Compile and Run
Make sure you have a C++ compiler
